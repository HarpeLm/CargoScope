# Blind Judge

The second blind benchmark of unused-dependency detection: 80 repositories never used in an earlier test ([repositories.txt](repositories.txt)), judged by the compiler on GitHub Actions ([../../../.github/workflows/blind-benchmark.yml](../../../.github/workflows/blind-benchmark.yml)).

- The tools are built once at the start of the run and frozen: CargoScope at the commit of the run, cargo-machete 0.9.2, cargo-shear 1.14.1 (default modes).
- Each repository runs on its own disposable runner ([judge-one.sh](judge-one.sh)): the tools first, then `cargo check --workspace --all-targets --all-features` with Rust 1.99.1 and rustc's `unused_crate_dependencies` lint, judged by [../compiler-judge/judge.py](../compiler-judge/judge.py), which uses no CargoScope code. Repositories that compile only without benches have their dev-dependencies left unjudged; those that do not compile are dropped.
- The last job scores the tools with [../compiler-judge/evaluate.py](../compiler-judge/evaluate.py) and uploads the `evaluation` artifact.

Unlike the first compiler benchmark, the runners have network access: they are disposable machines, so no container is needed to keep build scripts away from a personal computer.

Run it from the Actions tab (`Blind benchmark`, "Run workflow").

## Results (2026-11-15, [run 43713734487](https://github.com/HarpeLm/CargoScope/actions/runs/43713734487))

Tools frozen at the start of the run: CargoScope at commit `5a1057b`, cargo-machete 0.9.2, cargo-shear 1.14.1. No rule was changed after the run.

- 80 repositories; **56 judged** (49 with all targets and features, 7 without benches, whose dev-dependencies are not judged); 24 did not compile with Rust 1.99.1 and all features (newer minimum Rust versions, system libraries, nightly-only features) and were dropped.
- **566 dependencies judged.** rustc reports 22 unused, but only **3 are unused beyond reasonable doubt** (their name appears in none of the package's Rust files): these foundational crates have almost no unused dependencies.

| | Reported and judged by rustc | Correct | Wrong | Not judged by rustc | Certain unused found (of 3) |
|---|---|---|---|---|---|
| **CargoScope** (`likely-unused`) | 2 | 2 | **0** | 4 | 2 |
| CargoScope with `--show-uncertain` | 6 | 4 | 2 | 7 | 3 |
| cargo-machete (default) | 4 | 2 | 2 | 7 | 1 |
| cargo-shear (default) | 4 | 2 | 2 | 10 | 2 |

- **The 4 CargoScope findings rustc could not judge** are dev-dependencies of repositories compiled without benches. Read by hand, all 4 are really unused: `hex-literal` in RustCrypto's `cmac`, `getrandom` in `cms`, `x509-cert` in `gss-api`, `tempfile` in `x509-cert` (used by the separate `x509-cert-test-support` crate, which declares it itself). So **CargoScope's 6 default findings are all correct.**
- **The 2 errors of cargo-machete and cargo-shear are the same**: `prost` and `tonic-prost` in tower-http's tonic example, used by the code `tonic-build` generates. CargoScope lists them only as `possibly-unused` ("the sources include code generated by the build script").
- **The numbers are small**: 3 certain unused dependencies and a handful of findings per tool. What this run shows is that CargoScope's default output made no mistake on 56 repositories it had never seen; it does not measure a recall.
